# Deep Learning From Scratch — Lab Implementations

This repository contains my hands-on implementations of core Deep Learning concepts built entirely using **NumPy and basic Python**, without using ML frameworks such as TensorFlow, PyTorch, or scikit-learn.

The purpose of this repository is to understand how learning algorithms actually work internally instead of treating models as black boxes.

---

## What This Repository Covers

The labs progressively build a neural network from the ground up:

1. **Perceptron**

   * Binary classification
   * Weight update rule
   * Decision boundary understanding

2. **Logistic Regression**

   * Probabilistic outputs
   * Sigmoid activation
   * Cross-entropy loss

3. **Linear Regression from Scratch**

   * Gradient descent
   * Mean Squared Error
   * Continuous prediction

4. **Neural Network & Backpropagation**

   * Hidden layer computation
   * Activation functions (ReLU)
   * Manual gradient calculation

5. **Learning Non-Linear Relationships**

   * Multi-layer model
   * Error flow through network
   * Parameter updates via backpropagation

---

## Key Learning Outcome

Instead of calling library functions, every model here is implemented manually:

* Forward pass
* Loss calculation
* Gradient derivation
* Parameter updates

This helped me understand:

* How models actually learn
* Why activation functions matter
* How gradients flow in networks
* Difference between linear and non-linear models
